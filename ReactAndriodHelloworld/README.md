# React Android Hello World

![App Screenshot](./Screenshot%202026-05-02%20123052.png)

This is a simple React Native application designed to run on an Android Studio emulator. It contains various examples of styling text and views.

## Getting Started

1. **Install Dependencies**: 
   Make sure you have Node.js installed. If you haven't already, install the project dependencies:
   ```bash
   npm install
   ```

2. **Start the Development Server**:
   Run the following command to start the app:
   ```bash
   npm run android
   ```
  

## Features
- Built with Expo and React Native.
- Demonstrates fundamentals like `SafeAreaView`, `View`, and `Text` styling.
- Features hot-reloading for instant updates on the emulator.
